# Rule-Based AI Chatbot (Project 1)

A sleek, highly efficient rule-based AI chatbot designed to demonstrate mastery over control flow, logic, and data structure optimization in Python.

---

## 🚀 Key Feature: O(1) Efficiency
Unlike traditional rule-based chatbots that rely on messy `if-elif` ladders—which suffer from a linear lookup time of $O(n)$—this implementation utilizes a **Python Dictionary**. 

By leveraging the `.get()` method, the chatbot achieves a constant **$O(1)$ lookup time**, ensuring instantaneous responses regardless of how many rules or intents are added to the system.

---

## 🛠️ Tech Stack & Concepts
* **Language:** Python 3.x
* **Data Structures:** Python Dictionaries (Hash Maps)
* **Concepts:** Control flow optimization, time complexity management, and clean code architecture.
